# Customise

Read CLAUDE.md and the existing schema, CLI and compliance rules. Turn the requested field, stage or local rule into the smallest new numbered SQL migration. Back up the database first. Apply the migration to a temporary data directory and test the workflow using npm test. Update the CLI field allowlist, views, commands and docs together. Run npm run migrate on the intended database after the change has passed. Show the new field or rule with a real command. Do not edit an already applied migration. Do not invent a statutory interval. Keep the site competent person's source on each asset.
