# Why the database comes first

Maintenance is a record of equipment, work, parts, people and evidence. A coding agent runs the same commands a person can run and answers from those records. Postgres supports shared installations; embedded PGlite makes the local demo available without a server.

A screen offers fast mobile entry, camera capture, offline queues, drag-and-drop planning, barcodes and role-specific forms. This base offers text commands and read-only HTML snapshots. It has no phone app, offline capture, live refresh or authentication layer. Enterprise DNA can build the web or phone experience and connections your team needs around these records.

The weekly ritual is still concrete: triage requests, plan preventive work, assign the backlog, replenish stock and review inspection evidence. The database remains yours regardless of which agent opens it. Claude Code, Codex, OpenCode and Cursor use the same commands.
